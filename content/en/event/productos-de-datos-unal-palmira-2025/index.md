It covers version control with Git and GitHub, containers with Docker, APIs and the APIfication of software, cloud computing (AWS, Azure, GCP), SaaS/PaaS/IaaS models and DevOps. It introduces accessible platforms to deploy prototypes (Vercel, Netlify, GitHub Pages, Cloudflare Pages, Railway, Render, Shinyapps.io) and common architectures (monolith, microservices and serverless), closing with CI/CD automation as the goal."
